Privacy Policy

Last updated: February 12, 2026

Overview

WebLoad Troubleshooter is a browser developer-tool extension that helps diagnose page-load issues caused by content filters, blocked scripts, and failed dependencies. Your privacy is important to us, and this policy explains how the extension handles data.

Data Collected

The extension observes the following information only within your browser for the active tab while the DevTools panel is open:

  • Network request URLs, status codes, and response headers (e.g. Content-Security-Policy)
  • Failed or blocked network requests and their error reasons
  • Content-Security-Policy violation reports
  • JavaScript errors and unhandled promise rejections

How Data Is Used

All collected data is used solely to display diagnostic information in the extension's DevTools panel. The data is held in memory only for the lifetime of the tab and is automatically cleared when you navigate to a new page or close the tab.

Data Sharing and Transmission

WebLoad Troubleshooter does not:

  • Transmit any data to external servers
  • Use analytics or tracking services
  • Store data to disk, local storage, or any persistent medium
  • Share data with third parties

Permissions

The extension requests the following permissions:

  • webRequest and host_permissions (<all_urls>) — Required to monitor network requests across all sites so the extension can detect blocked resources and capture relevant response headers.

Changes to This Policy

If this policy is updated, the revised version will be included with the extension and the "Last updated" date above will change.

Contact

If you have questions about this privacy policy, please open an issue on the project's GitHub repository.
